## 本輪解決的操作細節

1. 真實保存前原本仍是「入耳式 (含耳道式)」和 123 字舊文案。先在耳機選单點「新增選項」，填「開放式」，點輸入框右側 **✓**，再從「自填選項」選取「開放式」。鄰近的 **×** 會取消輸入；✓ 未提供可用的 AX 名稱，需由當下畫面定位。
2. Quill 描述使用 `div.ql-editor[contenteditable]`：點擊、全選、刪除、確認 0／3000，再重新點擊並以純文字貼上完整文案。確認畫面 604／3000 才送出。
3. 刪空描述時出現的「1 個部份需要調整」提示在貼上後消失。送出後確實導回列表，不能把按鈕暂时停用當作保存證據。
4. 從列表點商品連結會開新分頁，需重新查分頁清單。新詳情已讀回「開放式」及 604 字全文，解決了舊紀錄曾發生的保存不持久化問題。
5. NCC 單碼主欄保留左耳值；右耳碼寫入有明確左／右標籤的描述，沒有再次把兩碼拼進單欄。
